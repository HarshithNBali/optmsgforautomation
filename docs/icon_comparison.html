Existing app SVG assets vs Lucide (stroke) vs Phosphor (fill) replacements — Generated 2026-03-28

Stroke vs Fill Icon Styles

Icon libraries use two fundamentally different drawing approaches. The existing OptMsg app uses stroke/outline style throughout — Lucide matches this perfectly. Phosphor uses fill/solid shapes which would visually clash with the current design language.

STROKE / OUTLINE (Lucide) — RECOMMENDED

Icons drawn with thin lines: fill="none" stroke="currentColor". Lightweight, modern. Matches the existing app's Iconsax-style SVGs. Easy to resize and recolor via CSS stroke property.

FILL / SOLID (Phosphor regular) — FOR COMPARISON

Icons drawn as solid filled shapes: fill="currentColor". Bolder visual weight. Would look heavier than the existing icons and clash with the current stroke-based design system.

Section D: Notes & Implementation Guidance
Key observations and action items
⚠ Dark Mode Issues (Hardcoded Colors)

The following SVGs have hardcoded colors that will NOT adapt to dark mode. They must be replaced or refactored to use currentColor:

  • more_hori.svg — fill: #747474 (medium gray, invisible on dark bg)
  • more_verti.svg — fill: #4C6043 (dark green, wrong color entirely)
  • replyBtn.svg — fill: #747474
  • forwardBtn.svg — fill: #747474
  • read.svg — stroke: #747474
  • attachments.svg — stroke: #747474
  • download.svg — fill: #1C5AD6 (hardcoded blue — use theme color instead)
✓ Icons Using White Stroke (Context-Dependent)

These SVGs use hardcoded white stroke — they were designed for dark/colored backgrounds. They will be invisible on white backgrounds. Review context before replacing:

  • search.svg — white stroke (used in dark nav bar)
  • compose.svg — white stroke (used in dark FAB)
  • filter.svg — white stroke (used in dark toolbar)
  • close.svg — white stroke (used in dark overlay)
  • delete.svg — white stroke (used in dark action bar)
  • arrowBack.svg — white stroke (used in dark app bar)
  • print.svg — white fill (used in dark toolbar)
📄 Migration Strategy
  1. Replace Icons.* Material icon usages with LucideIcons.* from the lucide_icons Flutter package
  2. For existing custom SVGs with hardcoded colors: replace with Lucide equivalents using color: Theme.of(context).iconTheme.color
  3. Keep existing custom SVGs that use stroke="#001625" as-is — they can be colorized via Flutter's ColorFiltered or SvgPicture with colorFilter
  4. Use SvgPicture.asset(..., colorFilter: ColorFilter.mode(color, BlendMode.srcIn)) for all SVGs to enable theming
📚 Lucide Flutter Package

Add to pubspec.yaml:

dependencies:
  lucide_icons: ^0.1.0

Usage in Flutter:

import 'package:lucide_icons/lucide_icons.dart';

Icon(LucideIcons.mail, color: Theme.of(context).primaryColor)
Icon(LucideIcons.archive, size: 24)
Icon(LucideIcons.tag)
